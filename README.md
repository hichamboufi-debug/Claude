# Dropshipping FR – application Android

Guide interactif pour apprendre et lancer un business de dropshipping en France.

- **Parcours** : 11 étapes (statut juridique, niche, fournisseurs, boutique, légal, paiement, publicité, service client, compta, croissance) avec conseils, liste de tâches cochables (progression sauvegardée) et liens utiles.
- **Ressources** : tous les liens regroupés, avec recherche.
- **Calculateur** : marge nette par vente, ROAS minimum de rentabilité.

Kotlin + Jetpack Compose (Material 3), aucune connexion ni compte requis.

## Obtenir l'APK
- GitHub : onglet **Actions** → dernier run « Build APK » → artefact `dropshipping-fr-debug-apk`.
- Ou Android Studio : ouvrir ce dossier, puis *Run*. En ligne de commande : `./gradlew assembleDebug`.

Contenu à but pédagogique : vérifiez toujours taux et règles sur les sites officiels.
